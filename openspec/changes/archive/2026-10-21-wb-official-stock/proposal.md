## Why

Остаток WB сейчас считается по ответам витрины в городах набора аккаунта, а витрина видит не все склады продавца. 21.10.2026 у артикула 180081238 (MAKIDS) мы показывали 3–10 шт. на размер, хотя у продавца было 91, 52 и 151 шт. Склад FBS «Балаково», где лежало 93 шт. размера 92, витрина не показала ни в одном из 33 городов. Официальный API продавца отдаёт остаток по всем складам сразу. По тому же артикулу FBS + FBO из API совпали с Evirma по 7 размерам из 10.

## What Changes

- Остаток размера берётся из официального API продавца, а не с витрины: сумма по всем складам продавца (FBS, включая DBS и экспресс) из Marketplace API плюс остаток на складах WB (FBO) из Аналитики.
- Остаток остаётся одной колонкой в таблице и в Excel. FBS и FBO не разделяются.
- Обход витрины по городам остаётся только для покупательской цены, СПП и кошелька. Набор городов больше не влияет на остаток.
- У остатка из API нет признака `>N`. Старые строки с `>N` показываются как раньше.
- Если остаток FBS или FBO не получен (у токена нет категории «Маркетплейс» или «Аналитика», токен не персональный и не сервисный, ошибка API), остаток всех размеров аккаунта за этот сбор пустой, а не 0, и задача пишет предупреждение, что исправить в токене.
- **BREAKING:** в день выкатки остаток у многих размеров скачком вырастет: появятся склады, которых витрина не видела. Это смена источника, а не движение товара. Токенам аккаунтов WB нужны категории «Маркетплейс» и «Аналитика», а токен должен быть персональным, иначе остаток будет пустым.

## Capabilities

### New Capabilities
- `wb-official-stock`: остаток размера WB из официального API продавца (FBS + FBO), требования к токену и поведение при ошибках.

### Modified Capabilities
- `wb-storefront-cities`: витрина по городам считает только цену. Требование «Остаток по набору городов» удаляется, а требования о сборе по набору и о городах без ответа больше не касаются остатка.
- `wb-city-selection`: набор по умолчанию — «7 regions», существующие аккаунты переводятся на него миграцией.
- `task-warnings`: новые случаи предупреждения, когда остаток из API не получен. Антибот и города без ответа больше не опустошают остаток.

## Impact

- `src/api/wb_api.py`: новые методы для складов продавца, остатков FBS и остатков FBO. Из обхода витрины убирается разбор и агрегирование остатков (`_collect_stock_observations`, `aggregate_size_stock`, `merge_size_stock`, `stock` в `WbSiteOffer`).
- `src/service/wb_service.py`: остаток строки берётся из результата API, плюс предупреждения об остатке.
- Схема БД не меняется: остаток пишется в `site_stock`, `site_stock_capped` = 0. Миграция `010_wb_cities_regions7.sql` ставит всем аккаунтам WB набор «7 regions».
- `templates/partials/wb_price.html`: подсказка в заголовке колонки остатка.
- Внешние API: `marketplace-api.wildberries.ru` (`/api/v3/warehouses`, `/api/v3/stocks/{warehouseId}`), `seller-analytics-api.wildberries.ru` (`/api/analytics/v1/stocks-report/wb-warehouses`).
